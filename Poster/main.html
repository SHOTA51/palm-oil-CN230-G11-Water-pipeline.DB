1Problem & Objectives

ข้อมูลปาล์มน้ำมันต้องเชื่อมโยงหลายปี หลายตัวชี้วัด และหลายระดับพื้นที่ เพื่อเปรียบเทียบและตรวจสอบแหล่งที่มาได้อย่างเป็นระบบ

  • จัดเก็บข้อมูลประเทศ ภาค และจังหวัดในฐานข้อมูลเดียว (1 ประเทศ · 4 ภาค · 76 จังหวัด)
  • แสดงแนวโน้มพื้นที่ยืนต้น พื้นที่ให้ผล ผลผลิต และ Yield
  • จัดอันดับพื้นที่ พร้อมค่าปีก่อนและสัดส่วนต่อประเทศ
  • เชื่อมระเบียนกับวันที่เผยแพร่ผ่าน release_id
  • ตรวจคุณภาพข้อมูล โดยแยกค่า 0 ออกจากข้อมูลที่ขาดหาย

ขอบเขตที่มีโค้ดรองรับ: meta(), trend(), ranking(), regions() ใช้คำสั่งอ่านข้อมูลและ bind parameters · SRS ครอบคลุมการนำเข้า ตรวจสอบ ส่งออก และ Drill-down แต่โค้ดที่แนบยังไม่ยืนยันว่าทำงานครบ

5Key Query: แนวโน้มรายพื้นที่

SELECT ps.crop_year AS year,
  MAX(CASE WHEN ps.item_id = 1 THEN ps.value END) AS planted,
  MAX(CASE WHEN ps.item_id = 2 THEN ps.value END) AS harvested,
  MAX(CASE WHEN ps.item_id = 3 THEN ps.value END) AS production,
  MAX(CASE WHEN ps.item_id = 4 THEN ps.value END) AS yield,
  MAX(dr.data_date_th) AS release_th
FROM production_stats ps
LEFT JOIN data_releases dr ON dr.release_id = ps.release_id
WHERE ps.location_id = :location_id
GROUP BY ps.crop_year ORDER BY ps.crop_year;

-- นำเข้าจาก Staging: สำเร็จทั้งชุด หรือยกเลิกทั้งชุด
BEGIN;
  INSERT ... ON DUPLICATE KEY UPDATE ...;  -- UPSERT (BR-12)
COMMIT;   -- สำเร็จ
ROLLBACK; -- เมื่อผิดพลาด
  • ใช้ EXPLAIN เปรียบเทียบแผนก่อน–หลังเพิ่ม Index (เวลา และจำนวนแถวที่อ่าน)
  • พิจารณาความซ้ำซ้อนกับ Index เดิมก่อนสร้างเพิ่ม
  • ทดสอบนำเข้าซ้ำ ผลลัพธ์ต้องไม่เพิ่มระเบียนซ้ำ

โค้ดที่แนบเป็นฝั่งอ่านข้อมูล จึงยังไม่ใช่หลักฐานว่า Transaction, Rollback หรือประสิทธิภาพ Index ผ่านการทดสอบแล้ว
