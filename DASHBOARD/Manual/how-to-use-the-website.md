# How to: ใช้งานหน้าแดชบอร์ด

หน้าเว็บมีหน้าเดียว เรียงจากบนลงล่างดังนี้

## 1. ส่วนหัว

- ชื่อแดชบอร์ดและช่วงปีของข้อมูล (ปีเพาะปลูก พ.ศ. 2525–2567)
- ป้ายสถานะมุมขวาบน
  - 🟢 **ข้อมูลสด · MySQL**: ดึงข้อมูลจากฐานข้อมูลได้ปกติ
  - 🟡 **เชื่อมต่อฐานข้อมูลไม่สมบูรณ์**: มีบางกราฟโหลดไม่สำเร็จ ให้ดู [troubleshooting.md](troubleshooting.md)

## 2. ค้นหาและถามผู้ช่วย AI

พิมพ์คำถามเป็นภาษาไทยในช่องค้นหา แล้วเลือกปุ่มใดปุ่มหนึ่ง

| ปุ่ม | ทำอะไร |
|---|---|
| **ค้นหา** | ค้นหาข้อความในฐานข้อมูลที่เกี่ยวข้องกับคำถามมากที่สุด 8 รายการ (semantic search) |
| **ถาม AI** (หรือกด Enter) | ค้นหาแบบเดียวกัน แล้วส่งผลลัพธ์ให้ Gemini เขียนคำตอบสรุป พร้อมเลขอ้างอิง เช่น [1] [2] (RAG) |

- คลิกเลขอ้างอิงในคำตอบเพื่อไปยังแหล่งข้อมูลนั้น
- คลิกชื่อแหล่งข้อมูลเพื่อดูข้อความเต็มที่ AI ใช้ตอบ
- **ดูบนแดชบอร์ด**: เปลี่ยนตัวกรองด้านล่างไปที่พื้นที่และปีของแหล่งข้อมูลนั้นทันที
- ป้ายมุมขวาของกล่องบอกโหมดการค้นหา
  - **ค้นหาเชิงความหมาย · gemini-embedding-001**: ใช้ Gemini เต็มรูปแบบ
  - **ค้นหาด้วยคำ (ยังไม่ได้เชื่อม Gemini)**: ยังค้นหาได้ แต่จับคู่ตามตัวอักษร (เอาเมาส์ชี้ที่ป้ายเพื่อดูสาเหตุ)

ตัวอย่างคำถามที่ใช้ได้ดี

- จังหวัดไหนผลิตปาล์มน้ำมันมากที่สุดในปี 2567
- ผลผลิตกระบี่ปี 2560 เท่าไหร่
- ภาคอีสานปลูกปาล์มน้ำมันกี่ไร่
- ผลผลิตต่อไร่ของชุมพรสูงสุดปีไหน
- ตาราง production_stats เก็บข้อมูลอะไร

## 3. แถบตัวกรอง

ตัวกรองมีผลกับทุกส่วนที่อยู่ด้านล่าง (การ์ดสรุปและกราฟทั้งหมด) แถบนี้จะติดอยู่ด้านบนจอเมื่อเลื่อนหน้าลง

| ตัวกรอง | ความหมาย |
|---|---|
| **พื้นที่** | ทั้งประเทศ, 4 ภาค หรือ 76 จังหวัด (จังหวัดจัดกลุ่มตามภาค) |
| **ปีเพาะปลูก (พ.ศ.)** | เลือกจากรายการ หรือกดปุ่ม ‹ › เพื่อเลื่อนทีละปี |
| **ตัวชี้วัด** | เนื้อที่ยืนต้น / เนื้อที่ให้ผล / ผลผลิต / ผลผลิตต่อไร่ |

## 4. การ์ดสรุป

แสดงค่าทั้ง 4 ตัวชี้วัดของพื้นที่และปีที่เลือก พร้อมร้อยละการเปลี่ยนแปลงเทียบกับปีก่อนหน้า (▲ เพิ่ม, ▼ ลด)
คลิกการ์ดเพื่อเปลี่ยนตัวชี้วัดของกราฟได้เหมือนกัน ถ้าจังหวัดนั้นยังไม่มีข้อมูลในปีที่เลือกจะขึ้นว่า "ไม่มีข้อมูล"

## 5. กราฟแนวโน้ม

กราฟเส้นของตัวชี้วัดที่เลือก สำหรับพื้นที่ที่เลือก ตลอด 43 ปี

- เอาเมาส์ชี้เพื่อดูค่าของแต่ละปี
- **คลิกที่กราฟเพื่อเปลี่ยนปี** (หรือกดลูกศรซ้าย/ขวาบนคีย์บอร์ดเมื่อกราฟถูกเลือกอยู่)
- เส้นแนวตั้งจาง ๆ คือปีที่กำลังเลือก

## 6. อันดับจังหวัด / ภาค

- เลือกระดับ **จังหวัด** หรือ **ภาค**
- ในระดับจังหวัดเลือกดู **ทุกภาค** หรือเฉพาะภาคใดภาคหนึ่งได้
- คอลัมน์ **สัดส่วนประเทศ** = ค่าของจังหวัดนั้นหารด้วยค่าทั้งประเทศในปีเดียวกัน (ไม่แสดงสำหรับผลผลิตต่อไร่ เพราะเป็นอัตราส่วน)
- คอลัมน์ **เทียบปีก่อน** = ร้อยละการเปลี่ยนแปลงจากปีก่อนหน้า
- แสดง 15 อันดับแรก กด **แสดงทั้งหมด** เพื่อดูครบ
- **คลิกแถวใดก็ได้** เพื่อเปลี่ยนพื้นที่ทั้งหน้าไปที่จังหวัดนั้น

## 7. เปรียบเทียบรายภาค

กราฟเส้น 4 เส้นของ 4 ภาค สีของแต่ละภาคคงที่เสมอ (ภาคกลาง น้ำเงิน, ภาคใต้ ส้ม, ภาคเหนือ เขียวอมฟ้า, ภาคตะวันออกเฉียงเหนือ เหลือง)
ภาคใต้ผลิตเกือบทั้งหมดของประเทศ เส้นภาคอื่นจึงอยู่ใกล้แกนล่าง ให้ชี้ที่กราฟเพื่อดูตัวเลขของทุกภาค

## 8. เกี่ยวกับฐานข้อมูล

ตารางทั้ง 6 ตารางพร้อมจำนวนแถวที่นับสด ๆ จากฐานข้อมูล และข้อควรรู้ในการอ่านข้อมูล

## 9. "ดูคำสั่ง SQL ที่ใช้"

ทุกการ์ดมีปุ่มนี้ด้านล่าง กดแล้วจะเห็นคำสั่ง SQL จริงที่ API ใช้ดึงข้อมูลชุดนั้น เหมาะสำหรับนำเสนอในวิชาฐานข้อมูล

## ธีมมืด/สว่าง

เว็บเปลี่ยนเป็นธีมมืดหรือสว่างตามการตั้งค่าของระบบปฏิบัติการโดยอัตโนมัติ
