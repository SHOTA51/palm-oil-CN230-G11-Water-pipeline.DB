# การนำเข้าไฟล์ CSV ของแดชบอร์ดลงใน MySQL

โฟลเดอร์นี้มีข้อมูลที่ส่งออก (Snapshot) จากฐานข้อมูล MySQL ที่กำลังทำงานอยู่เมื่อวันที่ 14 พฤศจิกายน 2026 โดยประกอบไปด้วยตาราง ERD จำนวน 6 ตารางที่ใช้สำหรับเว็บไซต์ ส่วนตาราง `stg_*` อีก 3 ตารางถูกคัดออกอย่างตั้งใจ เนื่องจากเป็นแค่ข้อมูลดิบที่นำเข้าและไม่ได้มีความจำเป็นต่อตัวเว็บแอปพลิเคชัน

## ไฟล์ CSV ต่างๆ

| ไฟล์ | จำนวนแถว | วัตถุประสงค์ |
|---|---:|---|
| `locations.csv` | 81 | ข้อมูลลำดับชั้นของประเทศ ภูมิภาค และจังหวัด |
| `commodities.csv` | 1 | ป้ายกำกับชื่อสินค้า (Commodity) |
| `units.csv` | 3 | หน่วยการวัด |
| `items.csv` | 4 | ตัวชี้วัดและหน่วยของมัน |
| `data_releases.csv` | 9 | วันที่เผยแพร่ข้อมูลจากแหล่งที่มา |
| `production_stats.csv` | 6,960 | ข้อมูลสถิติหลักที่ใช้ทำกราฟและการค้นหา |

ไฟล์ทั้งหมดเป็นรูปแบบ CSV เข้ารหัส UTF-8 และมีแถวหัวตาราง (Header) ข้อมูลได้รวมคีย์หลัก (Primary keys) เอาไว้แล้ว เพื่อให้ความสัมพันธ์ของคีย์นอก (Foreign-key) ยังคงอยู่สมบูรณ์ ส่วนช่องข้อมูลที่เว้นว่างไว้จะถูกแทนที่ด้วยค่า `NULL` ใน SQL

## การนำเข้าข้อมูลไปยังฐานข้อมูล MySQL ใหม่

แนะนำให้ใช้ฐานข้อมูลปลายทางที่ว่างเปล่า การนำเข้าข้อมูลลงในตารางที่มีข้อมูลอยู่แล้วอาจทำให้เกิด Error จากคีย์ซ้ำได้ ไฟล์ CSV เหล่านี้ทำมาเพื่อให้รองรับ MySQL 8.4 ซึ่งตรงกับโครงสร้างข้อมูล (Schema) ของโปรเจกต์พอดี

1. คัดลอกโฟลเดอร์ `export_csv` ทั้งโฟลเดอร์นี้ไปยังคอมพิวเตอร์เครื่องที่จะทำการนำเข้าข้อมูล
2. สร้างตารางโดยใช้สคริปต์ `DATA_SET/sql/01_create_tables.sql` ตัวอย่างเช่น เปิด MySQL client ขึ้นมาแล้วรันคำสั่ง:

   ```sql
   SOURCE C:/path/to/DATA_SET/sql/01_create_tables.sql;
   ```

   คำสั่งนี้จะสร้างและเรียกใช้ฐานข้อมูลชื่อ `plam-oil` รวมถึงสร้างตาราง ERD ทั้ง 6 ตาราง (ส่วนตาราง Staging ไม่จำเป็นสำหรับการนำเว็บขึ้นใช้งานจริง)

3. เปิด MySQL client โดยตั้งค่าให้สามารถโหลดไฟล์จากในเครื่อง (Local file loading) ได้ สำหรับการเปิดผ่าน Command-line ให้ใช้คำสั่ง:

   ```powershell
   mysql --local-infile=1 -h 127.0.0.1 -P 3306 -u YOUR_USER -p
   ```

   *หมายเหตุ: เซิร์ฟเวอร์ MySQL จะต้องอนุญาตให้ใช้ `LOCAL INFILE` ด้วย โดยสามารถตรวจสอบได้ด้วยคำสั่ง `SHOW VARIABLES LIKE 'local_infile';`*

4. เปิดไฟล์ `DATA_SET/export_csv/import_exports.sql` แล้วแก้ไขพาธ `C:/path/to/DATA_SET/export_csv` ให้เป็นพาธจริง (Absolute path) ของโฟลเดอร์ในเครื่องคุณ (แนะนำให้ใช้เครื่องหมายทับ `/` (Forward slash) สำหรับกำหนดพาธ)
5. กลับมาที่ MySQL client และรันคำสั่งต่อไปนี้:

   ```sql
   SOURCE C:/path/to/DATA_SET/export_csv/import_exports.sql;
   ```

สคริปต์นำเข้านี้จะทำการโหลดข้อมูลลงตารางหลักและตาราง Dimension ก่อนตาราง `production_stats` เพื่อรักษาความสัมพันธ์ของ ID และจะแปลงช่องที่เว้นว่างไว้ใน CSV ให้เป็นค่า `NULL` โดยอัตโนมัติ หากฐานข้อมูลของคุณไม่ได้ชื่อ `plam-oil` ให้ไปแก้ชื่อฐานข้อมูลในบรรทัด `USE` ของสคริปต์นำเข้า และแก้ในสคริปต์สร้าง Schema ก่อนรัน

## การตรวจสอบความถูกต้องหลังนำเข้า

ให้รันคำสั่ง Query นี้เพื่อเปรียบเทียบดูว่าจำนวนข้อมูลตรงกันหรือไม่:

```sql
SELECT 'locations' AS table_name, COUNT(*) AS row_count FROM locations
UNION ALL SELECT 'commodities', COUNT(*) FROM commodities
UNION ALL SELECT 'units', COUNT(*) FROM units
UNION ALL SELECT 'items', COUNT(*) FROM items
UNION ALL SELECT 'data_releases', COUNT(*) FROM data_releases
UNION ALL SELECT 'production_stats', COUNT(*) FROM production_stats;
```

ผลลัพธ์ที่ได้ควรจะเป็น 81, 1, 3, 4, 9 และ 6,960 แถวตามลำดับ เว็บแอปพลิเคชันจะสามารถ Join ตาราง `production_stats` เข้ากับตาราง Dimension อื่นๆ ได้โดยใช้ ID ที่อ้างอิงตาม ERD

**ข้อควรระวัง:** เวลาทำตัวกรอง (Filters) ควรให้ผู้ใช้เลือกสถานที่ในระดับเดียว การเอาข้อมูลระดับประเทศ ภูมิภาค และจังหวัดมาบวกรวมกันจะทำให้เกิดการนับข้อมูลของพื้นที่นั้นซ้ำซ้อน (Double-count)
